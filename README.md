# Python Basic Programs

A simple Python project containing basic programs for calculating a square, adding two numbers, and printing a name.

## Files

* `square.py` – Calculates the square of a number.
* `addition.py` – Adds two numbers.
* `name.py` – Prints a name.

## How to Run

Make sure Python is installed on your computer.

Open the project folder in a terminal and run any script using:

```bash
python square.py
```

```bash
python addition.py
```

```bash
python name.py
```

## Example Usage

### `square.py`

**Example output:**

```text
Enter a number: 5
Square: 25
```

### `addition.py`

**Example output:**

```text
Enter first number: 10
Enter second number: 20
Sum: 30
```

### `name.py`

**Example output:**

```text
Yatharth
```
